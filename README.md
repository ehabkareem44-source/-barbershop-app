# سيستم إدارة صالون الحلاقة — متصل بـ Supabase

موقع ويب كامل لإدارة الصالون (حجزات، مبيعات، مخزن، حسابات، دعاية) مع تسجيل
دخول للموظفين بـ username وباسورد، وقاعدة بيانات حقيقية على Supabase بتتزامن
لحظيًا بين كل الأجهزة.

## 1) إعداد مشروع Supabase

1. روح على [supabase.com](https://supabase.com) واعمل حساب / سجل دخول.
2. اعمل **New project** (اختار اسم وباسورد لقاعدة البيانات واحفظه).
3. لما المشروع يخلص إعداد، روح على **SQL Editor** → **New query**، وانسخ فيه
   محتوى ملف `supabase/schema.sql` الموجود في المشروع ده، واضغط **Run**.
   الكود ده هيعمل:
   - جدول `shop_data` (فيه كل بيانات الصالون كـ JSON واحد).
   - جدول `staff` (لربط اسم المستخدم بالإيميل).
   - صلاحيات (RLS) تسمح بس للموظفين المسجلين دخول بالتعديل.
   - تفعيل الـ Realtime على `shop_data`.
4. روح على **Project Settings → API** وهتلاقي:
   - **Project URL**
   - **anon public key**
   احفظهم، هتحتاجهم في الخطوة الجاية.

## 2) إعداد حساب صاحب المحل

الموقع بيستخدم Supabase Auth (إيميل + باسورد) تحت الغطاء، لكنه بيدخل
**برقم تليفونه** وإحنا بنحوله لإيميل تلقائي في الخلفية.

1. من **Authentication → Users → Add user** في Supabase، اعمل حساب بإيميل
   وباسورد (مثلاً `owner@salon.local` — مش لازم يبقى إيميل حقيقي، بس لازم
   يبقى بصيغة إيميل صحيحة، واختار الباسورد اللي هيستخدمها).
2. روح على **SQL Editor** ونفذ (غيّر الرقم والاسم حسب بياناته):
   ```sql
   insert into public.staff (username, email, full_name)
   values ('01000000001', 'owner@salon.local', 'صاحب المحل');
   ```
   ملاحظة: الرقم لازم يتكتب أرقام بس من غير مسافات أو رموز.
3. كده هيقدر يسجل دخول برقم التليفون ده + الباسورد اللي حطيته.

لو حبيت تضيف موظف تاني بعدين، كرر نفس الخطوتين برقم تليفون مختلف.

## 3) تشغيل المشروع محليًا

يتطلب [Node.js](https://nodejs.org) نسخة 18 أو أحدث.

```bash
npm install
cp .env.example .env
```

افتح ملف `.env` وحط فيه الـ `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`
اللي جبتهم من خطوة (1).

```bash
npm run dev
```

هيفتح على `http://localhost:5173`.

## 4) النشر (Deployment)

أسهل طريقة هي [Vercel](https://vercel.com) أو [Netlify](https://netlify.com)
(مجانيين للمشاريع الصغيرة):

### Vercel
1. ارفع المشروع على GitHub repo.
2. من Vercel: **Add New Project** → اختار الـ repo.
3. Framework Preset: **Vite**.
4. في **Environment Variables** ضيف:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
5. Deploy.

### Netlify
1. ارفع المشروع على GitHub.
2. **Add new site → Import an existing project**.
3. Build command: `npm run build` — Publish directory: `dist`.
4. في **Site settings → Environment variables** ضيف نفس المتغيرين فوق.
5. Deploy.

بعد النشر، هتاخد رابط زي `https://your-salon.vercel.app` تقدر تديه لصاحب المحل.

## نظام "الدور" (الطابور)

- العملاء بيدخلوا على `https://your-salon.vercel.app/queue` (رابط عام، مش محتاج
  تسجيل دخول)، بيكتبوا اسمهم ورقم تليفونهم، وبيتحطوا في الدور تلقائيًا.
  الصفحة بتوريهم مكانهم في الدور وبتتحدث لحظيًا.
- انت (صاحب المحل) بتدير الدور من تبويب **"الدور"** في لوحة التحكم: تقدر
  تدّي أي عميل دوره، تعلّم إنه خلص، تلغي حجزه، أو تمسحه خالص.
- تقدر تنسخ رابط `/queue` من نفس التبويب وتحطه في بيو إنستجرام أو تبعته
  واتساب، عشان العملاء يحجزوا مكانهم وهما لسه في البيت.
- أي عميل يحجز دوره بيتضاف تلقائيًا لقايمة العملاء، فتقدر بعد كده تبعتله
  عروض من تبويب **"الدعاية"** (قوالب جاهزة + إرسال مباشر واتساب بضغطة زر،
  من غير أي اشتراك أو API خارجي).

## هيكل المشروع

```
src/
  supabaseClient.js   -> الاتصال بـ Supabase
  App.jsx             -> يتحقق من تسجيل الدخول ويوجه للصفحة المناسبة
  Login.jsx           -> شاشة دخول الموظفين (username + password)
  BarbershopSystem.jsx-> لوحة التحكم كاملة (نفس الكود الأصلي + ربط Supabase)
supabase/
  schema.sql          -> إعداد الجداول والصلاحيات على Supabase
```

## ملاحظات مهمة

- **البيانات مشتركة بين كل الموظفين** (بلوك JSON واحد بيتزامن لحظيًا عبر
  Realtime) — مناسب لصالون واحد بفريق صغير. لو عايز فروع متعددة منفصلة
  ببيانات مستقلة لكل فرع، محتاج تعديل بسيط (صف `shop_data` منفصل لكل فرع).
- الباسورد وتسجيل الدخول بيتم بالكامل عبر Supabase Auth (آمن، مش مخزن في
  الكود).
- لو حبيت تلغي وصول موظف، امسح حسابه من **Authentication → Users** في
  Supabase مباشرة.
